The Clogged Downloads Problem

Managing downloads and documents is a repetitive manual chore, plagued by three major bottlenecks:

  • Unstructured Mess: The standard Downloads folder gets cluttered with mixed tax files, bank statements, medical reports, and bills.
  • Data Leakage Risk: Uploading sensitive personal papers (pension details, properties, IDs) to cloud organizers exposes private metadata.
  • Model Timeout/Failure: CPU-based local LLM systems often lock up or fail when processing heavy taxonomies with hundreds of potential folders.
📥 ➔ 📁?
Manual sorting requires reading content, extracting dates, generating names, and sorting folders.

The Privacy-First Solution

LAFO runs silently in the background, making autonomous, local routing decisions:

  • Zero Cloud Exposure: 100% offline. Uses local HuggingFace embeddings and Llama 3 via local Ollama. No data ever leaves your computer.
  • Robust Background Daemon: Integrates Windows Watchdog observers (`on_moved`) to capture browser rename events instantly.
  • Smart Renaming & Deduplication: Standardizes naming patterns with dates, and matches SHA-256 hashes to prevent file duplicates.

Data Flow Architecture

LAFO leverages a structured, multi-threaded pipelines orchestration system:

  • File Event Polling: Watchdog observes Downloads, triggers after files stabilize.
  • Candidate Pre-Filtering: FAISS searches directory taxonomy + file exemplars to select the top 3-5 folders.
  • Structured Agent: Ollama uses native JSON mode to classify documents, outputting date, filename, and confidence.

New in Version 1.3

Single-Instance Protection

Uses Windows-specific msvcrt file locks on lafo.lock to block duplicate orchestrator daemons, preventing polling race conditions.

Candidate Pre-Filtering

Pre-filters 302 categories down to 3-5 candidates via FAISS, reducing LLM context window to 1.5KB to avoid Ollama CPU timeouts.

Exemplar-Based Indexing

Indexes the first 15 files in target folders as exemplars in the FAISS database to automatically learn and match your established naming conventions.

Reliable Quarantining

Failed routing results are automatically moved to Unsorted_Review, preventing downloads directory congestion and infinite retry loops.

Multithreading & GPU Optimization

System performance has been tuned to handle parallel ingestion and high-throughput workloads:

  • ThreadPoolExecutor: Monitored files are dispatched to a background thread pool (max 4 workers) so browser downloads never freeze.
  • System Operations Lock: Critical filesystem transactions (duplicate checking, moving, logging) are serialized via thread locks.
  • CUDA Auto-Detection: Vector store embeddings leverage PyTorch GPU (CUDA) capabilities when available, falling back to CPU.

Service Automation & Deployment

Setting up LAFO on Windows takes less than 5 minutes and runs completely silently:

  • register_startup.ps1: Installs LAFO as a silent startup background process at user logon (injects shortcut in Startup folder).
  • unregister_startup.ps1: Safely terminates running background orchestrator instances and removes logon registrations.
  • Configurable Thresholds: Set confidence levels (default 75%) in config.py. Adjust model paths and OCR settings in seconds.
